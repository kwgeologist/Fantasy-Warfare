# Roadmap

Gate 0: native Windows user acceptance passed (user-confirmed controls, terrain, movement, pause and all cameras).

Gate 1: implemented tactical foundation and Windows package, with all 44 original simulation tests plus 11 terrain/measurement regressions, both original engine suites, HUD/render integration and seven playable terrain measurements. Reproducible seeded combat and unexpected-reserve replanning are required evidence, not a compile-only milestone. Current delivery still needs native Windows acceptance of new selection/groups, terrain consequences, combat and AI behavior.

Smallest next increment: address issues from Gate 1 Windows acceptance, especially moving-formation congestion, control clarity and combat balance. Only then plan stronger scouting/intelligence/AI benchmark work from the master protocol. Do not automatically start another gate.

Campaign, magic, siege, multiplayer, AI map reconstruction and dungeons are not part of this assignment. No speculative modules have been introduced for them. Large-army performance remains a future benchmarked goal.

Gate 1 remains open specifically for native Windows acceptance of the compact HUD and terrain consequences. Current correction results and reproduction steps are in GATE1_CORRECTIONS.md. Gate 2 has not begun.
