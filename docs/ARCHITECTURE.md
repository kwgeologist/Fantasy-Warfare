# Tactical foundation architecture

`src/Simulation` remains a pure .NET 8 library with no Godot dependency. `Battle` owns a single identified formation roster, fixed clock, seeded RNG, pending deliveries, movement paths, combat/morale state, faction perceptions and commander telemetry. `Formation` has identity/faction/definition/initial and current strength, ammunition, facing, fatigue, cohesion, morale, status and current order. No separate authoritative army roster exists in rendering or selection.

Files separate responsibilities: `Models` contracts/definitions/RNG; `Battle` fixed scheduling, order receipt and movement; `TerrainMap` immutable authored geometry, movement/LOS and deterministic path search; `Combat` simultaneous damage and morale/fatigue; `Intelligence` observation snapshots; `TacticalCommander` knowledge-only planning; `Selection` ID selection; `ScenarioCodec` validated versioned data. Default scenario JSON lives in `scenarios/skirmish.v2.json`, embedded in the shared library so headless and Godot use the same roster/stats.

A 50 ms tick delivers scheduled orders by delivery tick/ID, updates knowledge, periodically plans from snapshots, moves formations, resolves combat from pre-damage strengths, updates morale, refreshes observations and checks victory. AI orders use the same next-tick delivery path as player commands. Damage is aggregated before application, so first faction iteration does not get a first-strike casualty advantage. Movement/contact arbitration uses stable formation IDs; full simultaneous crowd motion is not implemented.

Movement uses integer millimetres and deterministic grid costs/queue tie breaks. Eight-neighbor A* integrates forward surface/slope travel costs with circular clearance; smoothing must preserve or reduce cost and retains exact targets. Clear direct lines are compared with cheaper forest/road detours. Height-field queries use the same corner/triangle interpolation as rendered collision; melee contact and blocked-rank behavior are independent of render collision. Local formation contact prevents overlap and permits brief sidesteps after waiting; congested traffic can still stall. Group targets retain initial relative offsets and cap base speed to the slowest selected type; terrain/path differences can stretch the group.

`game/Scripts/BattleView` reads authoritative state and handles selection, cameras, HUD, terrain/formation meshes, order indicators and volley tracers. Hidden enemies have both mesh visibility and picking collision disabled. No enemy order arrows or live commander reasoning are shown. It retains frame-time conversion remainders and discards paused wall time. All three views render one scene. `SelectionOverlay` is presentation-only. Troop meshes are aggregate visual proxies, not separately simulated soldiers.

The original single-formation constructor is a regression configuration of the same engine (flat traversable map, legacy movement rate, combat/morale/AI/victory disabled); no second simulation library or independent unit state is introduced. All eight original tests are preserved unchanged in substance. `--smoke` runs the original control fixture; `--gate1-smoke` runs the tactical fixture. Headless tests use the same 1280x720 logical viewport so real drag thresholds are exercised.

Conservative Gate 1 abstractions: formation salvos, immediate attacks, instantaneous facing, shared faction contacts, fixed observation radius/forest-depth rules, bounded rule/utility commander and army-wide rout/destruction victory. They are documented limitations, not claims of advanced military realism, ballistics, crowd simulation or strategic AI. No later-scope modules are scaffolded.

`CompactHud` is presentation-only: bottom status/command bar, selected-only scrollable details, collapsed help and focus-free buttons calling the existing input adapter. `TerrainTrials` isolates unit travel on the playable skirmish map; fixed-tick distance/arrival diagnostics make its measured output independent of rendered frame sampling. `--corrections-smoke` checks actual mesh colours, collision heights and HUD actions; `--terrain-trial=0..6` runs playable movement fixtures. `--terrain-demo=0..6` pauses each visible fixture for user observation.
