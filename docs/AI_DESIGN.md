# First commander and information boundary

`TacticalCommander.Plan(ArmyKnowledge, TerrainMap)` takes owned immutable value snapshots and copied observed contacts, plus public authored geography. It receives no Battle, live Formation, actual enemy roster, enemy orders or global visibility bypass. Own strengths/ammo/fatigue/morale and legitimately observed enemy attributes are available to both sides under shared simulation rules.

The baseline evaluates local observed strength versus nearby own support; chooses supported engagement or regroup; refuses cavalry frontal attacks on observed non-routing spearmen; screens threatened own archers; withdraws archers from melee threats and recognizes depleted ammunition. Safe routed survivors may rally without replacing casualties. With no contact it advances through public staging/scouting points rather than using concealed enemy coordinates. Commitment windows are 60 ticks for ordinary plan changes, 100 for repeated same plan/target; emergency avoidance/protection/regroup/ammo changes can interrupt earlier. Decisions are reevaluated every 20 ticks. This is a testable bounded rule/utility baseline, not advanced adaptive strategy or GOAP/HTN.

Memory contains commitments and last-known observations only. Stale contacts retain last seen positions and are not current attack targets. Physical contact and recent bow fire produce observations through sensor rules; collision resolution may use actual local geometry, but remote hidden positions never enter the planner/path search.

Reproducible surprise fixture: enemy archer 1 is known; enemy spear reserve 2 starts concealed in woods. Scheduled actual movement leaves concealment. Faction 2 chooses Exploit at tick 1 without knowing ID 2, observes the reserve, chooses AvoidSpears at tick 81, and delivers a withdrawal order. The test asserts the observation IDs, increasing decision time and received command, not just a changed string. Hidden-world variants change reserve position/strength and must produce identical pre-discovery plans.

Further tests cover spear-front avoidance, archer withdrawal/screens, ammo boundaries, stale position integrity, the API boundary, complete seeded/frame-independent combat traces and real combat in the default playable scenario. Full decisions/beliefs are retained in headless state for test analysis; active gameplay does not expose enemy intentions. Future AI improvements must be benchmarked against this baseline rather than described as clever without evidence.
